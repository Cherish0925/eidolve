# Universe

**Universe is the central concept of Eidolve.**

It is the persistent, shared world that connects everything intelligence and research may need to know, find, understand, use, create, or change.

The Universe includes information and knowledge, but it is not limited to either. It includes files, data, code, papers, media, experiments, evidence, claims, concepts, memories, questions, methods, decisions, failures, results, models, agents, people, tools, environments, systems, projects, histories, and the relations among them.

Its scope is not defined by a file format, database schema, model architecture, application, organization, or machine. It must remain continuous across systems, servers, versions, users, projects, sessions, and generations of intelligence.

## One world, not a collection of silos

Today the same work is divided among repositories, drives, databases, wikis, search indexes, chats, notebooks, model contexts, experiment trackers, project tools, and personal memory. Each system preserves only a fragment, and the relations among fragments are repeatedly lost.

Eidolve begins from the opposite premise: these fragments belong to one world.

A paper and the code that implements it; an experiment and the decision it changed; a conversation and the research direction it created; a model and the data, tools, environment, evaluation, and failures that shaped it; a file and the concepts, people, projects, versions, and evidence connected to it—all should remain part of the same Universe.

## Broader than any single system

The Universe is not another name for a database, file system, knowledge graph, wiki, search engine, memory system, model, agent framework, workflow, infrastructure stack, or training platform.

Those systems address different parts of the problem:

- files preserve original artifacts;
- databases structure and operate on data;
- graphs express relations;
- wikis synthesize shared understanding;
- search discovers and ranks what matters;
- Git preserves evolution and distributed contribution;
- memory carries experience across time;
- models and agents interpret, reason, research, decide, and act.

Eidolve seeks to make them cooperate around the same underlying world rather than remain separate products with separate realities.

## A world for intelligence

The Universe is built for AI, LLMs, agents, humans, and research systems together.

For a person, it should make complex bodies of work understandable, searchable, connected, and reusable. For a model or agent, it should provide persistent knowledge and experience beyond a temporary context window. For a research system, it should connect questions, literature, hypotheses, methods, code, experiments, evidence, decisions, results, and unresolved problems into a continuous research world.

The current context of an agent is therefore not the Universe itself. It is only the part of the Universe selected and organized for the present task. Memory is not a separate universe either; it is the part of past experience that remains meaningful and usable within the shared world.

## A world that develops

The Universe is not a static archive. New artifacts enter it. Relations are discovered. Knowledge is synthesized. Claims are supported, revised, or rejected. Research opens new questions. Models and agents create new interpretations and capabilities. People reorganize and deepen shared understanding.

The history of these changes is part of the Universe, not incidental metadata. The system must preserve both what is currently understood and how that understanding developed.

## The purpose

The purpose of Eidolve is to make knowledge, research, experience, and capability persist beyond the boundaries that currently fragment them.

A model may be replaced. An agent may end. A session may close. A project may move. A server may disappear. A file may be renamed. A system may be rebuilt. The Universe should continue.
